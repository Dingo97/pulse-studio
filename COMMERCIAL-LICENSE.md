Perimeter License 1.0.0. It may not be used to provide others with a product
or service that competes with Pulse Studio.

A separate commercial license is required when you want to:

- offer Pulse Studio or a derivative as a hosted service;
- sell, rent, sublicense, white-label, or bundle Pulse Studio as a product;
- integrate Pulse Studio into a competing commercial product or service;
- use Pulse Studio code in a product whose functionality or value substitutes
  for Pulse Studio.

Commercial licenses may grant rights not available under the Community
Edition license. Until a dedicated licensing address is published, contact the
repository owner privately through the GitHub profile associated with the
official Pulse Studio repository.

Using Pulse Studio to create videos, subtitles, thumbnails, captions, or other
creative deliverables for yourself or for clients does not by itself require a
commercial software license. See [OUTPUT-RIGHTS.md](OUTPUT-RIGHTS.md).

This page summarizes the intended licensing model. If it conflicts with the
Community Edition license, the text in [LICENSE](LICENSE) controls.
